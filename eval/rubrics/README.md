# Evaluation rubrics

`script_quality_v1.json` 是项目最初确定的口播文案评分体系，也是当前默认细则。当前文件版本为
1.1.0：保留原始七个 1～3 分 Judge 维度和一个独立规则计算的长度维度，但细化了可观察锚点与
口播封顶条件。长度分与七维分直接相加后按总满分归一化；引用只辅助“主题明确与信息量”的判断，
Reward-hacking 与引用风险作为正式评分的两个前置门控，不另加评分维度。两项均通过后才运行
长度规则和七维 Judge；任一项未通过则停止八维评分，最终分为空并保留原因。检测异常标为未完成。
门控实现和指纹独立版本化，现有 Rubric 内容及哈希保持不变。

`script_quality_v2.json` 保留用于复现 iteration-08～17 的证据链实验。它包含额外的字数维度、
标题链和证据完整性门控，不再用于默认评分。

评分文件记录 Rubric 版本和 SHA-256；修改锚点时应新增版本，不要直接覆盖已用于正式实验的文件。
