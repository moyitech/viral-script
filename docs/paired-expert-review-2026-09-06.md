# 两种写稿流程的专家配对评审结论

记录日期：2026-09-06。本文记录已收到的两位专家评审结果及其解释，不修改生成流程或默认配置。

## 1. 核心结论

在本次 100 个选题、300 对稿件的采用偏好评审中，两位专家总体都更愿意采用单次生成稿。
当前多阶段主编写稿流程没有体现采用偏好收益，不能继续笼统表述为“主编流程整体更好”。

本实验比较的是基于同一冻结研究背景的两种写稿方式：

- `editorial_candidates`：三候选生成、主编合并及必要的长度修复。
- `single_shot`：基于相同研究背景，一次生成正文。

结果不否定 Agent 的选题、检索和研究环节，也不意味着所有多阶段 Agent 都不如单次生成。
相同目标字数不等于实际长度完全相同；稿件未为评审而改写。

## 2. 样本与统计口径

两位专家分别评审全部 300 对：100 个选题，每题 280、450、700 字三个目标长度。
全量纳入，未按模型分数或门控筛选。每对隐藏来源、固定随机排列 A/B；主编在 A、B 各 150 对，
题目顺序也已打乱。两位专家使用同一排列，未进行跨评审者位置反转。

已核对样本编号唯一且完整、两份表正文与模板一致，并校验来源对应表与全部 600 条冻结
trace 的正文、task_id 和 SHA-256。采用偏好、可用性和理由均无缺失；两人均只选 A 或 B，
“无明显偏好”和“无法判断”均为零。

## 3. 采用偏好

| 专家 | 主编稿 | 单次生成稿 | 单次生成偏好率 | 按选题聚类的 95% 区间 |
| --- | ---: | ---: | ---: | ---: |
| CT | 75 | 225 | 75.0% | 69.7%–80.3% |
| KLD | 111 | 189 | 63.0% | 58.0%–68.0% |

分母均为每位专家的 300 次判断。区间使用按选题聚类的百分位 bootstrap：100 个选题有放回
抽样，每次保留同题三档稿件，重复 20,000 次，NumPy default_rng 种子为 20260906。
该区间只反映本次题目抽样的不确定性，专家固定为这两位，不代表创作者总体的不确定性。
两位专家对同一批稿件的 600 次判断不能当成 600 个独立样本。

| 目标字数 | 每位专家评审对数 | CT 单次生成偏好率 | KLD 单次生成偏好率 |
| --- | ---: | ---: | ---: |
| 280 | 100 | 68% | 40% |
| 450 | 100 | 76% | 69% |
| 700 | 100 | 81% | 80% |

450、700 字稿方向一致；280 字稿存在分歧，KLD 更偏好主编稿。因此不能写成“单次生成在
所有长度下都更好”。分长度结果为描述性分析，未据此作经多重比较校正的显著性结论。

作为口径敏感性检查，仅纳入双方均通过正式门控的 293 对时，CT 选择单次生成 221 对
（75.4%），KLD 选择单次生成 186 对（63.5%），总体方向不变。该子集不替代全量主结果。

## 4. 评审一致性与可用性

| 配对判断 | 对数 |
| --- | ---: |
| 两人都选择单次生成 | 150 |
| 两人都选择主编 | 36 |
| CT 选主编、KLD 选单次 | 39 |
| CT 选单次、KLD 选主编 | 75 |

选择一致率为 186/300 = 62.0%。Cohen’s κ = 0.126：按双方边际偏好计算偶然一致概率
为 0.565，再以 (0.62−0.565)/(1−0.565) 计算。总体方向相同，但逐篇判断的一致性有限。

| 专家与流程 | 可直接采用 | 小改可用 | 需大改 | 不可用 |
| --- | ---: | ---: | ---: | ---: |
| CT：主编 | 0 | 84 | 216 | 0 |
| CT：单次 | 0 | 180 | 120 | 0 |
| KLD：主编 | 50 | 228 | 21 | 1 |
| KLD：单次 | 85 | 195 | 20 | 0 |

两位专家的可用性标准明显不同。相对采用偏好与能否直接发布应分别报告，不能由偏好率推断
可直接发布率，也不把两稿均需大改视为平局。

## 5. 解释与限制

- CT 的“是否见过任一稿”全部填写“不确定”，KLD 全部填写“否”。不能确认 CT 完全未见过
  原稿，也不能仅凭表格证明评审过程完全独立。正式报告应披露这一盲化限制。
- 主编放在 A 时的获选率高于放在 B 时：CT 为 34.0% / 16.0%，KLD 为 43.3% / 30.7%。
  不同位置对应不同稿件，不能直接归因于位置偏差；后续可采用跨评审者位置反转设计。
- 从部分备注看，多阶段稿存在信息堆积、过强断言和事实核查成本等问题线索；另一些备注
  肯定其钩子、类比和口播表达。尚未系统编码备注，也未独立复核其中事实判断，不能将线索
  当作已证实的退化机制。
- 没有候选生成、主编合并、长度修复的逐环节消融，无法确定哪个步骤造成差异。
- 样本来自当前固定题库、模型与提示词配置，且只有两位专家。采用意愿不是实际发布、
  播放量、完播率或传播收益。

## 6. 与模型评分的关系

双方通过门控的 293 对上，首轮八维配对平均差（单次生成减主编）为：Hy3 −0.029721、
GPT-5.6-Luna +0.007395、GLM-5.3-Flash −0.004408。不同裁判对流程方向存在分歧。
本次专家总体偏好与 Luna 的平均差方向一致，但方向一致不证明 Luna 的逐篇排序更准确。

后续报告必须区分三个问题：重复评分稳定性、人与人及模型与人的一致性、流程质量差异。
模型稳定打满分不代表有区分能力；合并不同流程样本后的相关性变化也不代表评测器性能提升。

## 7. 产品与实验建议

建议把“研究后单次生成”作为默认写稿方案，将多阶段写稿保留为实验方案，尤其优先考虑
450、700 字场景。此项为基于当前证据的建议，尚未变更程序默认行为。

继续保留 Agent 的检索与研究能力。若迭代主编流程，应分别验证候选选择、合并、长度修复的
效果，用新的留出样本重新进行配对评审，避免只针对本次反馈调优后在同一批样本上宣称提升。
280 字场景因评审分歧，应单独验证。补充评审者并确认既往接触情况后，再扩大结论适用范围。
