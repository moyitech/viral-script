# 人工偏好测评结论

更新日期：2026-09-12。本记录报告两位评审者对两种写稿流程的整体采用偏好。

## 分析范围

比较同一冻结研究背景下的 Agent 多阶段写稿流程（三候选生成、主编合并及必要长度修复，
editorial_candidates）与端到端单次生成（single_shot）。比较的是写稿流程，不评价
Agent 选题、检索与研究环节的价值。

100 个选题、每题三个目标长度，共 300 对原稿。每对目标字数相同，实际字数可能不同。
两位评审使用同一批来源隐藏的 A/B 排列，主编稿位于 A、B 各 150 对。
两份表的样本编号和正文已逐项对齐，均完成 300 次明确选择、声明未见过原稿。
本记录只汇总整体采用偏好，不按目标长度展开，也不报告可用性或评审者间相关、一致性指标。

## 整体采用偏好

| 评审者 | 判断次数 | 选择 Agent 主编稿 | 选择端到端单次生成稿 | Agent 偏好率 |
| --- | ---: | ---: | ---: | ---: |
| 第一位 | 300 | 261 | 39 | 87.0% |
| 第二位 | 300 | 184 | 116 | 61.3% |
| **合计** | **600** | **445** | **155** | **74.2%** |

“无明显偏好”“无法判断”和缺失均为零。按样本编号连接来源对应表，将选择的 A/B
转换为具体流程，不能直接把选择 A 的比例解释为 Agent 偏好率。
第一位 Agent 偏好率为 261/300，第二位为 184/300；两人等权汇总为 445/600，
四舍五入后为 74.2%。端到端单次生成合计为 155/600，即 25.8%。

600 次判断来自同一批 300 对稿件、100 个选题，不是 600 个独立样本。
这里报告描述性的偏好比例，不据此作忽略题目和评审重复关系的显著性声明。

## 结论

在同题、同目标字数、共享研究背景的 300 对稿件人工盲评中，两位评审选择 Agent
多阶段生成稿的比例分别为 87.0% 和 61.3%，合计为 74.2%。结果支持：
**在本次样本和评审条件下，Agent 多阶段写稿流程具有更高的人工采用偏好。**

“更好”限定为更愿意采用，不延伸为事实准确性、生成成本或实际传播效果均更好，
也不表示全部专家或创作者的共识。没有逐环节消融，无法确定候选生成、主编合并和长度修复
各自的贡献。不同模型裁判的评分分歧仍见主报告，不能由人工偏好消除。
本次更新文档，不修改程序默认流程。
