# HyScript 任务 1：模型输出评估报告

> 本报告只评价 Hy3 生成的口播文案及其评测结果，不评价项目工程质量、产品完整度或参赛
> 交付完成度。

## 1. 评估结论摘要

本次实验以 100 个固定开放式选题为输入，每题最终选定一份经实时检索形成的冻结研究背景；
检索失败题按不可变 attempt 重试。每份背景用于生成 280、450、700 字三档文案，共得到
300 条模型输出。所有输出均成功冻结并完成 rules + Hy3 Judge 事后独立批量评分，没有生成
失败或门控失败。

首轮评测平均归一化总分为 **0.9969**：280 条为 1.0000，18 条为 0.9583，2 条为
0.9167。八个维度中，选题匹配度与主题明确/信息量全部得到 3 分；主要扣分来自长度偏差
（9 条）、合规边界（8 条），以及少量吸引力、口播、修辞和逻辑问题。700 字档出现唯一严重
长度不足样本：目标 700 字，实际 442 字。

高分不能解释为模型输出“接近完美”。生成模型和 Judge 均为 Hy3，正式集分数严重饱和；对
同一 300 条输出的第二轮 Judge 虽有 **99.05%** 的逐维完全一致率，但总分 Spearman 仅
**0.2734**，几乎没有足够的分数方差支持细粒度排序。进一步的攻击实验中，伪造引用、术语
堆砌和自我评分诱导全部错误通过。最稳妥的结论是：这些输出在当前 Rubric 下普遍满足主题、
结构和基本口播要求，但事实可靠性、长文长度控制、高风险措辞和自然候选间的细粒度优劣仍
需要独立校验或人工评审。

## 2. 评估对象与实验范围

### 2.1 模型输出

- 输入：仓库内项目构造的 100 个固定选题，覆盖 8 个领域和多类难例标签。
- 调研：每题由 Hy3 规划查询，Tavily 执行实时检索；失败题按 attempt 重试，最终每题选择
  一份冻结研究背景。
- 生成：每题从同一冻结背景生成 280、450、700 字版本，模式为 `editorial_candidates`。
- 输出：300 条冻结口播文案；同题三档共享研究背景，因此是相关样本，不是 300 个独立题目。
- 评测边界：只覆盖“已有选题 → 实时调研 → 文案生成”，不评价上游热榜发现、推荐质量、
  真实创作者采用率或视频传播效果。

生成阶段不读取评分结果，也不根据 Rubric 进行反馈改写。评分在轨迹冻结后单独运行，通过
`run_id`、轨迹 SHA-256 和 Rubric 指纹关联，避免评估信息进入被评对象。

## 3. 评分方法

### 3.1 八维 Rubric

正式评测使用 Rubric v1.1，各维度取 1–3 分。长度由确定性规则评分，其余七维由 Hy3 Judge
评分。Judge 使用 `high` reasoning、`temperature=0`、`top_p=1`，按内容、传播、口播和
安全拆成四组请求。

| 维度 | 评分者 | 3 分标准摘要 |
| --- | --- | --- |
| 选题匹配度 | Hy3 Judge | 正面回答题设，覆盖冲突两侧与核心人群 |
| 字数符合度 | rules | 非空白字符数相对目标偏差不超过 10% |
| 主题明确与信息量 | Hy3 Judge | 多个有效信息单元推进，事实、解释、结论互相支撑 |
| 吸引力 | Hy3 Judge | 开头有钩子，中段持续推进，结尾自然产生余味或互动 |
| 口播流畅度 | Hy3 Judge | 气口、重音和停顿自然，无需临时改词或重断句 |
| 修辞与记忆点 | Hy3 Judge | 修辞服务理解，存在自然且可复述的记忆点 |
| 语言逻辑与结构 | Hy3 Judge | 前提、解释、转折和结论递进，关键因果有桥梁 |
| 合规性 | Hy3 Judge | 不煽动、不夸大、不作无依据承诺，必要边界清楚 |

未触发门控时，八维等权汇总：

```text
final_score = 八个维度分数之和 / (8 × 3)
```

因此归一化分理论范围为 1/3–1，并非 0–1 min-max。重复凑字等结构性问题会触发硬门控，
门控后不提供可用最终分。完整行为锚点见
[Rubric v1.1](../eval/rubrics/script_quality_v1.json)。

### 3.2 实际评价次数

每条正式输出首轮执行一次确定性 rules 和一次完整 Hy3 Judge；为考察内部一致性，又对同一
条冻结输出独立执行了一次完整 Hy3 Judge。即每条输出有 **1 次 rules + 2 轮 Judge**。每轮
Judge 通常包含 4 次模型请求，解析失败时会重试，因此首轮 300 条共记录 1,269 次成功请求，
复评共记录 1,262 次成功请求。rules 是确定性的，复评时未重复运行。

| 配置项 | 取值 |
| --- | --- |
| 生成模型 | `hy3` |
| 生成采样 | temperature 0.9、top_p 1 |
| 生成模式 | `editorial_candidates`，不启用评估反馈改写 |
| Judge 模型 | `hy3` |
| Judge 采样 | `high` reasoning、temperature 0、top_p 1 |
| 任务 / Hy3 / 搜索 / Judge 并发 | 32 / 64 / 8 / 64 |
| 固定随机种子 | 20260902 |
| 数据集 SHA-256 | `698fb36b13c1911f1d5b4756579850bc94439389dc33a07b3bbcc4e32016c852` |
| Rubric SHA-256 | `87297b18d3ee076311a3046a8dfb58f645bccac48903896abebbdd68e795a9ab` |

研究阶段第一次 attempt 有 48 个题次、第二次有 3 个题次因三次搜索请求均失败而暂时标记为
证据不足；第三次补齐剩余 3 题，最终选择的 100 份研究背景全部成功。“51”是跨历史 attempt
累计失败记录数，并非最终仍有 51 个题目失败。

## 5. 典型模型输出分析

### 5.1 严重长度不足：T095-L700

该输出讨论“宠物进入商场，友好空间是否也该照顾怕动物的人？”，目标 700 字，实际只有
442 个非空白字符，偏差 36.86%。长度规则给出 1 分，其余七个 Judge 维度全部为 3 分，最终
仍得到 0.9167。这说明模型在长文长度修复后仍可能明显不足，也说明等权平均会稀释严重的单项
失败。证据见[冻结轨迹](../eval/experiments/formal-100-v1/generation/traces/attempt-001/traces/T095-L700-run-20260902T144958Z-16ce8b2b4bcd.json)和
[评分记录](../eval/experiments/formal-100-v1/results/items/run-20260902T144958Z-16ce8b2b4bcd/combined.json)。

### 5.2 吸引力与记忆点不足：T048-L280

该输出围绕公共 USB 充电风险给出建议，切题、信息、口播和结构均获 3 分，但吸引力与修辞
记忆点均为 2 分。Judge 认为开头虽进入主题，但前 20 字缺少强冲突；“顺线摸进”等局部表达
帮助理解，却没有形成自然、可复述的核心记忆点。最终分为 0.9167。证据见
[Judge 记录](../eval/experiments/formal-100-v1/results/items/run-20260902T143033Z-5544e05a8337/hy3_judge.json)。

### 5.3 口播局部拗口：T020-L700

该输出讨论共享单车禁停范围扩大。内容组织和记忆点获得 3 分，但“人在禁停区落锁，车收不到
信号，你走不了账”等局部措辞被判定需要改词或重断句，口播流畅度为 2 分，最终分 0.9583。
该样本只有口播流畅度被扣分，类似措辞可能增加实际录制时的修改成本。证据见
[Judge 记录](../eval/experiments/formal-100-v1/results/items/run-20260902T142053Z-20ba530b48a0/hy3_judge.json)。

### 5.4 指代与概念范围不清：T034-L280

该输出讨论家庭闲钱配置。Judge 指出“这类产品”指代突兀，现金类产品与储蓄国债的概念范围
可能混淆，因此逻辑结构为 2 分，其他维度为 3 分，最终分 0.9583。证据见
[Judge 记录](../eval/experiments/formal-100-v1/results/items/run-20260902T142510Z-1e5b852ccee3/hy3_judge.json)。

### 5.5 绝对化措辞带来合规扣分

合规性共有 8 条输出得到 2 分，常见模式是结论过于绝对。例如 `T034-L700` 用“抵消通胀”
描述收益效果，未限定收益率和通胀条件；`T050-L450` 将政策概括为“不让家长多掏钱”，容易
让观众误以为所有合理收费都违规；`T066-L280` 以“钱白花没减排放”概括碳信用问题，开头
范围过宽。按当前 Judge，292/300 条输出的合规性获得 3 分；这些扣分样本说明，模型为了口播
冲突感仍可能使用超出证据范围的强断言。

## 6. 重复评价：Judge 内部一致性

第二轮针对同一 300 条冻结输出、使用相同 Rubric 与 Judge 指纹重新评分。长度规则是确定性的，
因此一致性统计只比较七个 Judge 维度，共 2,100 个维度配对。

| 指标 | 结果 |
| --- | ---: |
| 逐维完全一致 | 2,080/2,100（99.05%） |
| 七维全部一致的输出 | 281/300（93.67%） |
| 首轮 / 复评平均 Judge 分 | 0.99810 / 0.99714 |
| 平均分变化 | -0.00095 |
| 总分 MAE | 0.003175 |
| 总分 Spearman | 0.2734 |

| Judge 维度 | 完全一致率 | 二次加权 Kappa | MAE |
| --- | ---: | ---: | ---: |
| 选题匹配度 | 100.00% | 1.0000 | 0.0000 |
| 主题明确与信息量 | 100.00% | 1.0000 | 0.0000 |
| 修辞与记忆点 | 100.00% | 1.0000 | 0.0000 |
| 语言逻辑与结构 | 99.67% | 0.0000 | 0.0033 |
| 吸引力 | 99.33% | 0.4975 | 0.0067 |
| 口播流畅度 | 99.33% | -0.0033 | 0.0067 |
| 合规性 | 95.00% | 0.2613 | 0.0500 |

绝对一致率很高，但不能简单写成“排序稳定”。大多数首轮分数均为 3，边际分布极不平衡，
使 Kappa 和 Spearman 受到大量并列分与极低方差影响。更准确的结论是：Judge 对这批高度
饱和输出通常重复给出相同绝对分，但缺少证明细粒度排序一致性的有效信号。合规性发生
15/300 次变化，是复评中最不稳定的维度。

例如 `T013-L280` 首轮吸引力和合规性均为 3 分，复评认为开头过早自答削弱钩子，且“找注销
才不踩坑”过于绝对，两个维度均降为 2 分。该例表明，强断言边界在两轮评分之间会发生波动。

## 7. 评测结果的可信度检查

本节评价“评分是否值得相信”，不是把派生攻击文本当作正式模型输出。

### 7.1 判别力实验

从正式输出中按“领域 × 长度”分组轮询选择 20 个不同题目的来源样本，并在每组内优先选择
正式高分输出。20 个来源输出的正式分均为 1.0，覆盖 7 个领域（未覆盖职场），三档长度分布
为 7/7/6。每条来源输出构造未修改、截断至约 62%、泛化替换三个版本。

| 预期等级 | 样本数 | 平均最终分 | 门控数 |
| --- | ---: | ---: | ---: |
| 未修改 | 20 | 1.0000 | 0 |
| 截断 | 20 | 0.8667 | 0 |
| 泛化替换 | 20 | 0.4167 | 0 |

20/20 组满足“未修改 > 截断 > 泛化替换”，60 个成对比较也全部正确。这证明评估器能够识别
这 20 组人为构造的强退化；由于选样偏向高分、未覆盖全部领域，“未修改”也没有经过人工
质量确认，因此不能把 100% 排序率泛化为自然候选之间的细粒度判别能力。

### 7.2 对抗实验

预先定义的错误通过条件为：攻击样本未被门控且最终分不低于 0.75，即八维原始平均分不低于
2.25。

| 攻击类型 | 样本数 | 被门控 | 错误通过 | 错误通过率 |
| --- | ---: | ---: | ---: | ---: |
| 伪造引用 | 5 | 0 | 5 | 100% |
| 重复凑字 | 5 | 5 | 0 | 0% |
| 术语堆砌 | 5 | 0 | 5 | 100% |
| 自我评分诱导 | 5 | 0 | 5 | 100% |
| **合计** | **20** | **5** | **15** | **75%** |

规则成功识别机械重复，却没有拦住另外三类语义攻击。尤其是伪造引用全部错误通过，说明正式
输出中的高“主题信息量”分不能被解释为事实或引用已经核实。当前 50 项人工盲评模板尚未
回收，因此本报告没有 Judge—人工一致性证据。

## 8. 模型输出能力与边界

### 8.1 当前证据支持的能力

- 在固定选题和冻结检索背景下，300/300 条输出成功生成，任务执行完整。
- 当前 Judge 认为所有输出均切题且具备足够信息组织，绝大多数输出结构和口播表达完整。
- 280 字档 100/100、450 字档 97/100 的长度维度获得 3 分；5/5 个构造的重复攻击样本被规则
  门控。
- 输出的主要问题集中且可定位：长文长度尾部、绝对化表述、局部口播措辞、记忆点和指代衔接。

### 8.2 当前证据不支持的结论

- **不能证明事实准确或证据可追溯。** 当前八维没有独立逐句事实核验，伪造引用攻击全部通过。
- **不能证明自然候选排序可靠。** 正式分数高度饱和，重复评价 Spearman 较低，判别力样本又
  是人为强退化版本。
- **不能证明高风险领域安全。** 健康样本全部满分只是当前 Judge 结果，未经过医学或合规专家
  标注；合规性也是复评最易波动的维度。
- **不能证明真实传播效果。** 实验没有播放量、完播率、转发率、创作者采用率或用户满意度。
- **不能保证联网重跑得到相同输出。** Tavily 结果会随时间变化，`hy3` 是服务端模型别名；
  冻结记录可以审计和重算，但外部调用只能复现实验流程。

## 9. 后续改进优先级

1. 对正文事实与冻结证据做逐句对齐，对不存在来源的机构、数字、结论设置硬门控。
2. 将严重长度偏差升级为关键约束门控，避免目标 700 字、实际 442 字仍获得 0.9167。
3. 收紧金融、医疗、政策和安全话题中的绝对化措辞约束，并对合规分歧自动进入复核。
4. 增加自然低分、跨模型生成和边界样本，重新校准 Rubric，降低满分比例。
5. 完成 50 项双人盲评和第三人仲裁，补充人工 Kappa、Judge—人工 Spearman 与 MAE。
